# Sistema de Dados - Censo Escolar MG

## Objetivo
Analisar o impacto da pandemia nas matrículas escolares em Minas Gerais (2017–2024).

## Tecnologias
- Python
- Pandas
- Parquet
- Power BI

## Estrutura
- Bronze: dados brutos
- Prata: dados limpos
- Ouro: indicadores

## Como executar
1. Criar ambiente virtual
2. Instalar requirements
3. Rodar scripts em /src
